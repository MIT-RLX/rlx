# rlx-capi

The C ABI for rlx — graphs, sessions, device selection, autodiff, training,
text, weights and distributed nodes from any language with C interop: Swift, Go, C#, Java, Ruby, Julia, Zig, ….

```c
#include "rlx.h"

RlxGraph *g;  rlx_graph_new("mlp", &g);
size_t shape[2] = {1, 4};
uint32_t x, w, y;
rlx_graph_input(g, "x", shape, 2, NULL, &x);
size_t wshape[2] = {4, 2};
rlx_graph_param(g, "w", wshape, 2, NULL, &w);
rlx_graph_matmul(g, x, w, &y);
rlx_graph_set_outputs(g, &y, 1);

RlxSession *s;  rlx_session_new("cpu", NULL, NULL, &s);
RlxCompiled *c; rlx_session_compile(s, g, NULL, &c);   /* consumes g's graph */
```

* Every function returns `RLX_OK` or a negative `RLX_ERR_*`;
  `rlx_last_error()` holds the message.
* Handles are freed with their `rlx_*_free`; buffers and strings rlx returns
  with `rlx_u32s_free` / `rlx_f32s_free` / `rlx_bytes_free` /
  `rlx_string_free`. Structured results (reports, shapes, name lists) are JSON.
* An optional node is `RLX_NONE`; any other optional — and a defaulted string —
  is `NULL`.

`include/rlx.h` and the `rlx_graph_<op>` builders (`src/graph_ops.rs`) are
generated by `rlx-bindgen` from rlx-bind's op table (`just gen-bindings`); the
header is produced by parsing this crate, so it matches the library exactly.
The runtime functions follow rlx-bind's runtime API table (`api.idl`), and
`rlx-bindgen` fails when a row and its C function disagree. Optional features:
`gguf-convert` (`rlx_convert_to_gguf`), `fpga` (`rlx_export_fpga`).
[`examples/`](examples/README.md) has C programs that build, run,
differentiate and train a graph (`train_linear.c`), compose graphs
(`compose.c`) and run a packaged model (`models.c`). `tests/swift_package.rs`
runs the Swift binding built on this, and `tests/ffi_languages.rs` runs every
generated FFI-language binding's tests and examples against the library cargo
just built (`RLX_TEST_DOCKER=1` uses each language's container image when its
toolchain isn't installed).

Builds as `staticlib` (Swift, iOS, embedded) and `cdylib` (runtimes that load
a shared library). Backend features mirror rlx-runtime (`cpu` default,
`metal`, `gpu`, `cuda`, …). See [`docs/bindings.md`](../../../docs/bindings.md).
